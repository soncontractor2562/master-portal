================================================================================
📋 ข้อความสำหรับ Copy ไปสั่งงานใน "แชทใหม่" (สร้างโปรแกรมย่อย)
================================================================================
(Copy ข้อความด้านล่างนี้ทั้งหมด ไปวางเป็นข้อความแรกในแชทใหม่ได้เลยครับ)
--------------------------------------------------------------------------------

คุณเป็น AI ผู้เชี่ยวชาญด้าน Web Development ฉันต้องการให้คุณช่วยสร้าง "โปรแกรมย่อย (Sub-App)" ตัวใหม่ให้กับระบบของฉัน

⚠️ กฎข้อบังคับที่ห้ามฝ่าฝืนเด็ดขาด (Strict Isolation Rules):
1. [CSS Scoping] โปรแกรมนี้จะถูกนำไปฝัง (Integrate) ในระบบ Master Portal รวมภายหลัง 
   - ห้าม เขียน CSS กำหนดสไตล์ให้กับ body, html, :root หรือรีเซ็ตแท็กแบบครอบจักรวาล (*)
   - ให้สร้าง Wrapper ครอบ UI ทั้งหมดไว้ (เช่น <div class="subapp-wrapper"> หรือ <div id="my-app-root">) และเขียน CSS ให้อยู่เฉพาะภายใต้ Wrapper นั้นเท่านั้น เพื่อไม่ให้ CSS รั่วไหลไปกระทบโปรแกรมอื่น
2. [LocalStorage Prefix] ข้อมูลที่บันทึกใน LocalStorage หรือ SessionStorage ต้องใส่ Prefix เป็นชื่อแอพเสมอ (เช่น myapp_data, myapp_settings) ห้ามใช้ชื่อสั้นๆ ทั่วไปที่จะไปทับซ้อนกับแอพอื่น
3. [Theme Independence] ถ้ามีระบบ Dark/Light Mode ให้จัดการเฉพาะภายในตัวแอพเอง ห้ามไปเปลี่ยน attribute บนแท็ก <html> หรือ <body> นอก Wrapper
4. [Standalone Folder Structure] ให้จัดระเบียบไฟล์ไว้ในโฟลเดอร์เดียว เช่น:
   - index.html (หรือ App.jsx กรณีเป็น React)
   - style.css
   - app.js
   เพื่อความสะดวกในการยกทั้งโฟลเดอร์ไปเชื่อมต่อกับ Master Portal

หากเข้าใจกฎทั้ง 4 ข้อนี้แล้ว โปรดตอบรับสั้นๆ ว่าพร้อมทำงาน และรอรับรายละเอียด (Requirements) ของโปรแกรมที่ฉันจะแจ้งต่อไปได้เลยครับ
