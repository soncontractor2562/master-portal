สวัสดีครับ รบกวนช่วยพัฒนาโปรแกรมย่อยตัวใหม่สำหรับเชื่อมต่อเข้า Master Portal (SON CONTRACTOR)
โดยกรุณาอ่านและปฏิบัติตามกฎเหล็กในไฟล์ "Command&Rules/SUB_APP_DEVELOPMENT_RULES.md" อย่างเคร่งครัด:

1. วางโค้ดทั้งหมดไว้ในโฟลเดอร์: src/<app-id>/
2. ทำ CSS Scoping ให้ครอบด้วย class .<app-id>-root เสมอ ห้ามให้สไตล์รั่วไหล
3. หากมีฐานข้อมูล Supabase ให้ตั้งชื่อตารางขึ้นต้นด้วย <app-id>_ และเตรียมไฟล์ setup_<app-id>.sql มาด้วย
4. ไม่แก้ไข body/html หรือ Root Theme ของระบบหลัก

โจทย์โปรแกรมย่อยที่ต้องการพัฒนาคือ:
[ระบุรายละเอียด ฟังก์ชันการทำงาน และหน้าจอของโปรแกรมที่ต้องการที่นี่]

เมื่อพัฒนาเสร็จแล้ว รบกวนสรุปรายงานส่งมอบ (App ID, ชื่อเมนูภาษาอังกฤษ, คำอธิบายภาษาไทย, ไอคอน Lucide, Dependencies ที่ต้องติดตั้ง) ตามแบบฟอร์มใน Command&Rules/ส่งมอบโปรแกรมย่อย.txt ให้ด้วยครับ
