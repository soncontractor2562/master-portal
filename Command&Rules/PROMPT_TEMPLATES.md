# 💬 ชุดคำสั่งสำเร็จรูป (Prompt Templates)
> **สำหรับคัดลอกไปสั่ง AI แชทใหม่ เพื่อพัฒนาหรือประกอบร่างโปรแกรมย่อย**

---

## 📌 เทมเพลตที่ 1: สั่งแชทใหม่ให้ "พัฒนาโปรแกรมย่อยตัวใหม่"
*คัดลอกข้อความด้านล่างนี้ไปวางในแชทใหม่ที่ต้องการให้เริ่มเขียนโค้ด:*

```text
สวัสดีครับ รบกวนช่วยพัฒนาโปรแกรมย่อยตัวใหม่สำหรับเชื่อมต่อเข้า Master Portal (SON CONTRACTOR)
โดยกรุณาอ่านและปฏิบัติตามกฎเหล็กในไฟล์ "Command&Rules/SUB_APP_DEVELOPMENT_RULES.md" อย่างเคร่งครัด:

1. วางโค้ดทั้งหมดไว้ในโฟลเดอร์: src/<app-id>/
2. ทำ CSS Scoping ให้ครอบด้วย class .<app-id>-root เสมอ ห้ามให้สไตล์รั่วไหล
3. หากมีฐานข้อมูล Supabase ให้ตั้งชื่อตารางขึ้นต้นด้วย <app-id>_ และเตรียมไฟล์ setup_<app-id>.sql มาด้วย
4. ไม่แก้ไข body/html หรือ Root Theme ของระบบหลัก

โจทย์โปรแกรมย่อยที่ต้องการพัฒนาคือ:
[ระบุรายละเอียด ฟังก์ชันการทำงาน และหน้าจอของโปรแกรมที่ต้องการที่นี่]

เมื่อพัฒนาเสร็จแล้ว รบกวนสรุปรายงานส่งมอบ (App ID, ชื่อเมนูภาษาอังกฤษ, คำอธิบายภาษาไทย, ไอคอน Lucide, Dependencies ที่ต้องติดตั้ง) ให้ด้วยครับ
```

---

## 📌 เทมเพลตที่ 2: สั่งแชทผู้จัดการให้ "นำโปรแกรมย่อยมาประกอบร่างเข้า Master Portal"
*คัดลอกข้อความด้านล่างนี้พร้อมข้อมูลส่งมอบ มาวางในแชท Master Manager เพื่อให้รวมแอพ:*

```text
ช่วยนำโปรแกรมย่อยตัวใหม่ประกอบร่างเข้าสู่ระบบ Master Portal ตามคู่มือ "Command&Rules/INTEGRATION_GUIDE.md" ให้หน่อยครับ

รายละเอียดโปรแกรมย่อย:
- App ID: [เช่น petty-cash]
- ชื่อเมนู (Label): [เช่น Petty Cash]
- คำอธิบาย (Description): [เช่น ระบบบันทึกและเบิกเงินสดย่อย]
- ไอคอน (Lucide Icon): [เช่น Wallet]
- ตำแหน่งโฟลเดอร์โค้ด: src/[app-id]/
- คำสั่งติดตั้ง Library เพิ่ม (ถ้ามี): [เช่น npm install xlsx หรือ ไม่มี]
- ไฟล์ Database SQL (ถ้ามี): [เช่น setup_[app-id].sql]

รบกวนช่วยสร้าง View Wrapper, ผูก Lazy Loading + URL Hash, เพิ่มเมนูทั้ง Desktop/Mobile และทดสอบ Build & Push ขึ้น main ให้ด้วยครับ
```
